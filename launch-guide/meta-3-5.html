3.5 Ads Manager — кампания

Последний шаг: сама рекламная кампания, которая использует события из шага 3.4 для оптимизации. В архиве этой сессии нет подходящего реального скрина создания кампании — этот раздел ждёт скриншотов.

📸 Нужны скрины (Ads Manager → Кампании → Создать):
  1. Выбор цели кампании (Objective) — для установок приложения это «Promote your app».
  2. Уровень группы объявлений: выбор приложения/стора и события оптимизации (Optimization event) — например «Purchase» или «Install».
  3. Бюджет и геотаргетинг.
  4. Итоговый экран запуска кампании.
1

Что будет на этом шаге (конспективно)

Цель кампании «Продвижение приложения» привязывается к конкретному приложению из Meta for Developers (шаг 3.2) через выбор магазина (App Store/Google Play) и указание Store ID. Событие оптимизации — то самое, что мы видели живым в Events Manager (шаг 3.4): если там «Неактивно», кампания физически не может оптимизироваться под это событие, сколько бы бюджета в неё ни заложить.

🚫 Запускать/увеличивать кампанию без живых событий в Events Manager (статус «Неактивно» на шаге 3.4) — гарантированная трата бюджета без возможности оптимизации. Сначала 3.4 должен показать реальные события, потом сюда.
