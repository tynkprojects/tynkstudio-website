2.5 Реклама и рекламный идентификатор

Две разные декларации, которые легко спутать. «Реклама» — про показ рекламы внутри приложения. «Рекламный идентификатор» — про использование Advertising ID (для чего угодно, включая просто измерение чужой рекламы через Meta SDK).

1

Декларация «Реклама»

Контент приложения → Реклама. Единственный вопрос: показывает ли приложение рекламу (баннеры, интерстишлы, видео) пользователю внутри самого приложения.

1
✕

«Нет, моё приложение не содержит рекламу»

Верный ответ для Pawnia — несмотря на то, что подключён Meta SDK. Meta здесь используется только для измерения эффективности чужой рекламы (которая крутится в других приложениях), а не для показа рекламы в самом Pawnia. Эти две вещи раздел различает явно.

Документация: Реклама →
Реальный скрин Google Play Console автора.
2

Декларация «Рекламный идентификатор»

Отдельная страница — спрашивает, использует ли приложение (или сторонний SDK внутри него) Advertising ID. Ответ «Да» нужен, даже если ответ на «Рекламу» выше был «Нет»: Meta SDK читает рекламный ID для атрибуции, значит использование есть.

После «Да» нужно отметить цель использования — для Pawnia это «Реклама или маркетинг» (и при необходимости «Аналитика»), точно так же, как мы указывали для Apple App Privacy.

⚠️ Эта декларация обязательна для приложений, использующих AD_ID permission на Android 13+, независимо от того, показывает ли приложение рекламу само. Несовпадение этой декларации с реальным поведением SDK — то же нарушение, что и в App Privacy у Apple. Документация: Рекламный идентификатор →
